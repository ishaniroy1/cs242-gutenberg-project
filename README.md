# CS24200: Project 1 - TF-IDF

Parse Project Gutenberg plaintext ebooks using regex, calculate TF-IDF from scratch with NumPy and pandas, and extract document insights.

## Setup Instructions
You can download the required assets automatically using the provided setup script.

### Prerequisites
Ensure you have `curl` installed (typically built-in on macOS and most Linux distributions).

### Installation
Install all required libraries using pip:
```bash
pip install -r requirements.txt
```

Run the following:
```bash
chmod +x download_texts.sh
```
```bash
./download_texts.sh
```
